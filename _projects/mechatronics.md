This assignment is for MAE 3780, mechatronics. In teams of three we had to design, build, and code a robot that would collect as many blocks scattered around the board while competing with another team's robot on the same board. For this task, I was responsble for desining the cube catching mechanism to ensure the blocks would not fly out while the robot was turning. I also assisted in debugging the code as we initially struggled to use the color sensor to detect the black border.
